# Telegram-бот расписания СФУ

Бот-ассистент для студентов Сибирского федерального университета

## Функционал
- Просмотр расписания
- Напоминания о парах
- Заметки и домашние задания

## Стек
- Python 3.10+
- aiogram 3.x
- PostgreSQL
- SQLAlchemy

## Структура проекта
- `docs/` — документация (требования, дизайн, диаграммы)
- `src/` — исходный код
- `tests/` — тесты
