## 2. Учебные недели

Расписание СФУ задаётся отдельно для 1-й и 2-й недели. Учебные недели не совпадают с календарными, поэтому номер текущей недели задаёт администратор, а не бот.

**Как это работает:**

1. В начале семестра администратор вызывает `/set_week`
2. Бот: «Какая учебная неделя идёт сейчас?» — кнопки `1` / `2`
3. Бот: «С какого дня она началась? Введите дату понедельника в формате `ДД.ММ.ГГГГ`»
4. Бот сохраняет пару «номер недели + дата начала» в таблицу настроек
5. Дальше номер считается автоматически: `номер = ((дней_с_даты // 7) + стартовый_номер - 1) % 2 + 1`
6. Если недели сдвинулись (праздники, переносы), администратор повторяет `/set_week` — данные перезаписываются

Пока администратор не задал неделю, бот отвечает на запросы расписания: «Расписание ещё не настроено. Обратитесь к администратору».

## 3. Главное меню (ReplyKeyboardMarkup)

Постоянная клавиатура, показывается после регистрации. Расположение 2x3:

| | |
|---|---|
| 📅 Расписание | ⏰ Напоминания |
| 📝 Заметки | 📚 Домашние задания |
| 👥 Моя группа | ❓ Помощь |

Кнопки «Выбрать институт» и «Выбрать группу» в постоянное меню не выносятся: выбор делается один раз при регистрации, дальше группа меняется через «Моя группа».

## 4. Inline-клавиатуры

### Регистрация и смена группы

Выбор идёт каскадом, каждый шаг — отдельная клавиатура под сообщением:

1. Институт: список институтов СФУ (по 8 на страницу, кнопки «◀ Назад» / «Вперёд ▶»)
2. Курс: 1–6
3. Группа: список групп выбранного курса. Подгруппа входит в название группы, как она записана в файле расписания: `КИ24-01 (1 подгруппа)`, `КИ24-21 (2 подгруппа)`

### Расписание

Под сообщением с расписанием: `Пн` `Вт` `Ср` `Чт` `Пт` `Сб` — быстрый переход на другой день недели. Текущий день подсвечивается.

Расписание в файлах СФУ задано отдельно для 1-й и 2-й недели: в листе «Расписание» есть столбец «Неделя» со значениями `1` и `2`, и занятия одной и той же пары в эти недели различаются. Бот определяет номер текущей недели по настройке администратора (раздел 2) и показывает только относящиеся к ней пары. При переходе между днями номер недели не меняется.

### Напоминания

Под сообщением со списком `/reminders`:
- `➕ Создать` — то же, что `/reminder`
- `🗑 Удалить` — удаление выбранного напоминания с подтверждением
- `✏ Изменить время` — смена даты и времени

### Заметки и домашние задания

Под сообщением со списком:
- `➕ Создать`
- `🗑 Удалить`
- `📅 Дедлайны` — то же, что `/deadlines`

### Справка

- `📋 Показать список команд`

## 5. Общие правила

- Расписание, заметки и дедлайны форматируются по единому шаблону (задача 8.7).
- Номер недели (`1` или `2`) вычисляется от даты, которую администратор указал командой `/set_week`. Настройка хранится в БД, а не в конфиге: иначе при каждом сдвиге недель пришлось бы править файл и перезапускать бота.
- Если расписание для группы ещё не загружено, бот отвечает «Расписание для вашей группы пока не загружено» и не показывает пустой список (задача 5.5).
- Если в выбранный день пар нет — «В этот день пар нет».
- Все тексты кнопок и сообщений хранятся константами в `src/utils/config.py`.
