
# Структура интерфейса бота

##  1. Список команд 
    /start - Запустить бота и выбрать институт, группу  
    /schedule - Показать расписание  
    /today - Расписание на сегодня  
    /remind - Управление напоминаниями  
    /note - Мои заметки  
    /homework - Домашние задания  
    /help - Справка
## 2. Главное меню (ReplyKeyboardMarkup)  
    Кнопки (расположение 2x2 или 2x3):   
    Выбрать институт  
    Выбрать группу  
    Расписание  
    Напоминания  
    Заметки и ДЗ  
    Помощь
## 3. Inline-клавиатуры  
    При выборе расписания: [Выбор даты в текущем месяце] (бот сам определяет чётность недели в зависимости от выбранной даты)
    Под сообщением с напоминанием: [Создать]; [Выбрать] -> [Удалить напоминание]; [Редактировать напоминание] -> [Изменить текст напоминания]; [Изменить дату и время напоминанияя]
    При выборе помощи: [Показать список команд]; [Обратная связь]
    При выборе института/группы: [показать доступный список институтов/групп]
    Под сообщением с заметками и домашним заданием: [Создать]; [Выбрать] -> [Удалить заметку]; [Редактировать текст заметки]
