# Сценарии диалогов

Сценарии описывают основные пути работы с ботом. Названия команд и кнопок согласованы с `architecture.md` и `ui_structure.md`.

## Сценарий 1: Первое использование (выбор группы)

Обязательный сценарий: без выбранной группы остальные функции недоступны.

1. **Пользователь:** отправляет `/start`
2. **Бот:** «Привет! Я бот-ассистент СФУ. Давайте выберем вашу группу. Укажите институт:» — inline-кнопки (ИКИТ, ИУБП, ИЭУиП, …)
3. **Пользователь:** нажимает институт
4. **Бот:** «Выберите курс:» — кнопки 1–6
5. **Пользователь:** нажимает курс
6. **Бот:** «Выберите группу:» — кнопки с названиями групп, включая подгруппу: `КИ24-01 (1 подгруппа)`, `КИ24-21 (2 подгруппа)`
7. **Пользователь:** нажимает группу
8. **Бот:** «Готово! Ваша группа: КИ24-03Б (1 подгруппа).» — присылает главное меню (ReplyKeyboardMarkup) и краткую подсказку по командам

**Группа уже выбрана:**
1. **Пользователь:** отправляет `/start`
2. **Бот:** «Вы уже выбрали группу КИ24-03Б (1 подгруппа). Хотите сменить её?» — кнопки `Сменить` / `Оставить`
3. При «Сменить» — переход к шагу 2 основного сценария; при «Оставить» — возврат в главное меню

**Ошибка:** если на шаге 1–7 пользователь отправляет произвольный текст вместо нажатия кнопки, бот повторяет текущий шаг и напоминает, что нужно нажать кнопку.

## Сценарий 2: Расписание на сегодня

Предусловие: группа выбрана (иначе middleware `check_registration` перенаправляет на сценарий 1).

1. **Пользователь:** отправляет `/today` или нажимает «📅 Расписание» в главном меню
2. **Бот:** определяет группу пользователя, текущий день недели и номер недели (`1` или `2`)
3. **Бот:** присылает расписание:

```
Сегодня, четверг, 29 октября
КИ24-03Б (1 подгруппа)

1 пара  08:30–10:05
Системный анализ
лекция, ауд. 3-15, корп. 3
Иванов И. И.

2 пара  10:15–11:50
Статистический анализ данных
практика, ауд. 2-08, корп. 2
Петрова А. С.
```

4. Под сообщением — inline-кнопки дней недели `Пн` `Вт` `Ср` `Чт` `Пт` `Сб` для перехода на другой день

**Пустой результат:** если пар нет — «Сегодня, 29 октября, пар нет».
**Расписание не загружено:** «Расписание для группы КИ24-03Б пока не загружено. Попробуйте позже».

## Сценарий 3: Расписание на неделю

Предусловие: группа выбрана.

1. **Пользователь:** отправляет `/week`
2. **Бот:** определяет номер текущей недели (`1` или `2`) и запрашивает все пары группы за эту неделю
3. **Бот:** присылает расписание по дням, дни без пар пропускаются:

```
Неделя 26–30 октября
КИ24-03Б (1 подгруппа)

Понедельник
1 пара  08:30–10:05  Системный анализ (лекция), ауд. 3-15
2 пара  10:15–11:50  Теория эволюционных вычислений (практика), ауд. 2-08

Вторник
3 пара  12:00–13:35  Методы машинного обучения (лаборатория), ауд. 1-22
```

4. Если сообщение не помещается в лимит Telegram (4096 символов), бот разбивает его по дням и отправляет несколько сообщений (задача 8.9)

**Пустой результат:** «На этой неделе пар нет».

## Сценарий 4: Добавление напоминания

1. **Пользователь:** отправляет `/reminder` или нажимает «⏰ Напоминания» → `➕ Создать`
2. **Бот:** «О чём напомнить? Напишите текст напоминания»
3. **Пользователь:** вводит текст
4. **Бот:** «Когда напомнить? Введите дату и время в формате `ДД.ММ.ГГГГ ЧЧ:ММ`»
5. **Пользователь:** вводит `05.11.2026 08:00`
6. **Бот:** проверяет, что дата в будущем и формат верный, сохраняет напоминание и отвечает: «Напоминание создано: 05.11.2026 в 08:00 — подготовить отчёт»

**Ошибка формата:** «Не получилось разобрать дату. Введите в формате `ДД.ММ.ГГГГ ЧЧ:ММ`, например `05.11.2026 08:00`». Бот остаётся на шаге 5.
**Дата в прошлом:** «Эта дата уже прошла. Укажите будущую дату и время».
**Отмена:** в любой момент `/cancel` или кнопка «Отмена» — диалог прерывается, напоминание не сохраняется.

## Сценарий 5: Удаление напоминания (дополнительный)

1. **Пользователь:** отправляет `/reminders`
2. **Бот:** присылает список активных напоминаний и inline-кнопку `🗑 Удалить`
3. **Пользователь:** нажимает `🗑 Удалить`
4. **Бот:** показывает список напоминаний в виде кнопок
5. **Пользователь:** выбирает напоминание
6. **Бот:** «Удалить напоминание «подготовить отчёт»?» — кнопки `Да` / `Нет`
7. **Бот:** «Напоминание удалено» или «Отмена»

**Пустой результат:** если напоминаний нет — «У вас нет активных напоминаний».

## Сценарий 6: Установка учебной недели (администратор)

Предусловие: пользователь входит в список администраторов, проверяется middleware `check_admin`.

1. **Администратор:** отправляет `/set_week`
2. **Бот:** «Какая учебная неделя идёт сейчас?» — кнопки `1` / `2`
3. **Администратор:** нажимает `2`
4. **Бот:** «С какого дня началась 2-я неделя? Введите дату понедельника в формате `ДД.ММ.ГГГГ`»
5. **Администратор:** вводит `02.11.2026`
6. **Бот:** сохраняет настройку и отвечает: «Готово. Текущая неделя — 2, началась 02.11.2026. Дальше недели считаются автоматически.»

**Неверный формат:** «Не получилось разобрать дату. Введите в формате `ДД.ММ.ГГГГ`, например `02.11.2026`».
**Дата не понедельник:** «Дата начала недели должна быть понедельником».
**Дата в будущем:** «Дата начала недели не может быть в будущем».
**Не администратор:** команда не отображается в `/help`, при попытке вызова бот отвечает «Команда доступна только администратору».

Повторный вызов `/set_week` перезаписывает предыдущую настройку — так администратор исправляет сдвиг учебных недель.
