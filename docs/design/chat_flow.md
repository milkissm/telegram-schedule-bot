# Сценарии диалогов

## Сценарий 1: Первое использование (Выбор группы)

1. Пользователь: Отправляет /start
2. Бот: "Привет! Я бот-ассистент СФУ. Выберите ваш институт:" (присылает Inline-кнопки: ИКИТ, ИУБП...)
3. Пользователь: Нажимает одну из кнопок с указанием института
4. Бот: "Выберите курс:" (кнопки: 1, 2, 3, 4, 5, 6)
5. Пользователь: Нажимает кнопку с номером курса
6. Бот: "Выберите группу:" (кнопки: КИ24-06Б, КИ24-17/1Б...)
7. Пользователь: Нажимает одну из кнопок с номером группы
8. Бот: "Готово! Теперь вам доступно главное меню." (присылает Reply-клавиатуру)

## Сценарий 2: Добавление напоминания

1. Пользователь: Отправляет /remind
2. Бот: "Напишите своё напоминание"
3. Пользователь: описывает новое напоминание
4. Бот: "Введите дату и время в формате чч.мм.гггг чч:мм"
5. Пользователь: вводит дату и время в указанном формате

## Сценарий 3: Удаление напоминания

1. Пользователь: Отправляет /remind_delete
2. Бот: "Укажите напоминание, которое хотите удалить"
3. Пользователь: описывает или выбирает напоминание из указанных
4. Бот: "Уверены, что хотите удалить напоминание? (ниже уточнение напоминания)"
5. Пользователь: да или нет
6. Бот: "Напоминание удалено/Отмена действия"

## Сценарий 4: Список напоминаний

1. Пользователь: Отправляет /remind_list
2. Бот: отправляет список напоминаний с указанием даты и времени, а ниже предлагает дальнейшие варианты взаимодействий с напоминаниям, указанными в сценариях 2 и 3 или же возвращение в главное меню (1 сценарий)
